## Branch merges (safe-branch-merge)
Skill folder: `.claude/skills/safe-branch-merge` — read `.claude/skills/safe-branch-merge/SKILL.md` before any branch merge; scripts are in `.claude/skills/safe-branch-merge/scripts/`.
Key rules: never lose source code silently; report before merging (`~/Downloads/merge-reports/`); ask when unsure with developer name, date and snippets; never run git commit or git push.
